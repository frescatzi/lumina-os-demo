# Contributing

Thanks for your interest. This is a demo repository, so small focused changes are the most useful.

1. Open an issue first for anything beyond a typo, so we agree on scope.
2. Keep changes small and covered by a test in `tests/`.
3. Run `uv run python -m unittest discover tests` before opening a pull request.
4. Use synthetic data only. Never commit credentials, real hostnames, webhook URLs or personal data.
5. Workflow exports must contain no credential IDs and no instance-specific URLs.
